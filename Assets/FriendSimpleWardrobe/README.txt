かんたん衣装切替 1.0

VRChatのアクションメニューに、すでに着せ替え済みの衣装を追加するUnityエディター拡張です。
必要なものは Unity 2022.3、VRChat SDK - Avatars、Modular Avatar です。

1. .unitypackageをUnityプロジェクトにインポートします。
2. Hierarchyでアバターを選び、Tools → フレンド向け → かんたん衣装切替 を開きます。
3. アバターの下にある衣装オブジェクトを、画面の枠へまとめてドラッグします。
4. 最初に着る衣装の「初期」にチェックを入れ、「衣装切替メニューを作る・更新する」を押します。
5. シーンを保存し、VRChatのアクションメニュー「衣装切替」で確認します。

一度に選べるのは1着です。何も選択されていないときは「初期」の衣装に戻ります。
選択は保存・同期されます。8ビットの同期枠を使用します。
メニューを開き直すと登録済みの衣装を編集できます。「外す」は登録だけを外します。

衣装はアバターに合うように事前に取り付けてください。サイズ合わせ、ボーン結合、貫通修正は衣装側で行います。
着替えを管理する既存のトグルと同じ衣装を登録すると、表示設定が競合する場合があります。
既存衣装のModular Avatarによる体の非表示・変形処理は、着替え後にも確認してください。
アバター本体や衣装の素材はこのパッケージに含まれていません。
