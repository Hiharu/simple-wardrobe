# かんたん衣装切替 1.1.0

VRChatのアクションメニューに、すでに着せ替え済みの衣装を追加するUnityエディター拡張です。

## 前提条件

- Unity 2022.3、VRChat SDK - Avatars、Modular Avatarを導入したプロジェクト。
- Hierarchyに配置された、VRC Avatar Descriptor付きのアバター。
- アバター配下に取り付け済みの衣装が2〜32着。各衣装に表示用のRendererが必要です。
- 登録する衣装の親オブジェクトが有効で、階層名から各衣装を一意に参照できること。
- 同じ衣装の重複登録や、親子関係にある衣装の同時登録はできません。
- 新規導入時に同期パラメータ8ビット分の空きが必要です。ビルド後の合計もSDKで確認してください。

## 準備とダウンロード

1. VRChat用の機能を使う場合は、Creator CompanionなどでAvatarsプロジェクトを用意し、VRChat SDK - Avatarsを導入します。
2. 対象プロジェクトにModular Avatarを導入します。関連する依存パッケージも解決し、Unityのコンパイル完了を待ちます。
3. 下記のGitHub Releasesを開き、Assets欄から、このツール名の付いた拡張子が .unitypackage のファイルをダウンロードします。
4. Unityの Assets → Import Package → Custom Package からファイルを選び、Importを押します。
5. Consoleに赤いコンパイルエラーがある場合は、内容を確認して解消してからツールを開きます。

SDKの導入はCreator Companionの案内、Modular Avatarの追加は公式導入手順を参照してください。 [Creator Companion](https://vcc.docs.vrchat.com/) ・ [Modular Avatarの導入](https://modular-avatar.nadena.dev/docs/intro)

## 衣装の登録

1. .unitypackageをUnityプロジェクトにインポートします。
2. Hierarchyでアバターを選び、Tools → フレンド向け → かんたん衣装切替 を開きます。
3. アバターの下にある衣装オブジェクトを、画面の枠へまとめてドラッグします。
4. 最初に着る衣装の「初期」にチェックを入れ、「衣装切替メニューを作る・更新する」を押します。
5. Hierarchyのアバター直下に「かんたん衣装切替」が作られたことを確認します。
6. このオブジェクトのMA Menu Installerで、必要に応じてSelect Menuから配置先を選び、シーンを保存します。
7. 対象アバターをVRChat SDKでBuild & Testし、アクションメニュー「衣装切替」を確認します。公開済みアバターに反映する場合は、変更したアバターを再アップロードします。

## 環境チェック・診断結果の共有

画面下の **環境チェック** を押すと、Unity・SDK・Modular Avatar・NDMFのバージョン、選択したアバター、衣装登録条件、生成オブジェクトの有効状態、MA Menu Installer・Controller・パラメータの有無を確認できます。画面の導入ガイドから、この説明書とMAの導入ページを開けます。

困ったときは **診断結果をコピー** を押し、コピーされた文章に「どの段階で止まったか」「期待した動作」「実際の動作」を追記して送ってください。コピー時には再チェックするため、設定変更後の状態を取得します。表示済みの診断はチェック時点の記録です。

- アバター名・衣装名・ファイルパス・PCのユーザー名・Blueprint ID・Consoleログ本文は含めません。自動送信はしません。
- Package Managerに登録されないAssets形式の依存パッケージは、バージョンを取得できない場合があります。「登録なし」だけでは未導入と断定しません。
- 同期コストはDescriptorに直接設定された値です。MA統合後の総量や他ギミックとの競合は、SDKビルドで別途確認してください。
- 導入先メニューがDescriptorから見つからなくても、MA等で後から統合する構成があります。注意表示は確定エラーではありません。
- **SDK・MA不足などでプロジェクトがコンパイルできない場合、この画面も開けません。** その場合はVCCで依存関係を確認し、Consoleの最初の赤いエラーを共有してください。ログや画像に個人のパスが含まれる場合は、共有前に確認してください。

既存の生成Controllerが手作業などで変更されて読み込めない場合、1.1.0では画面を止めずに案内を表示し、誤った上書きを防ぎます。自動修復はしません。

## VRChatでの使い方

一度に選べるのは1着です。何も選択されていないときは「初期」の衣装に戻ります。
選択は保存・同期されます。8ビットの同期枠を使用します。
メニューを開き直すと登録済みの衣装を編集できます。「外す」は登録だけを外します。

衣装はアバターに合うように事前に取り付けてください。サイズ合わせ、ボーン結合、貫通修正は衣装側で行います。
着替えを管理する既存のトグルと同じ衣装を登録すると、表示設定が競合する場合があります。
既存衣装のModular Avatarによる体の非表示・変形処理は、着替え後にも確認してください。
アバター本体や衣装の素材はこのパッケージに含まれていません。

配布ファイルは [GitHub Releases](https://github.com/Hiharu/simple-wardrobe/releases/latest) からダウンロードできます。

## 動作確認

Unity 2022.3.22f1、VRChat SDK - Avatars 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8で検証しました。最低対応バージョンは未検証です。

SDK付属サンプルで、ビルド時のメニュー合成、衣装2着の切替、初期衣装の変更、選択解除時の初期衣装への復帰を確認しました。別環境で「メニューに表示されない」との報告があり、再現条件を調査中です。VRChat実機は未検証です。

メニューはModular Avatarのビルド処理で合成されます。アバター直下の「かんたん衣装切替」にあるMA Menu Installerを有効にし、Select Menuで導入先を確認してください。作成後に対象アバターをビルドしてください。

## 登録内容の変更・更新・削除

- 登録を変更するときは同じアバターでツールを開き、衣装や「初期」を変更して「衣装切替メニューを作る・更新する」を押します。
- 一覧の「外す」は登録欄からの除外です。変更を反映するには作成・更新ボタンを押してください。外した衣装の表示状態はHierarchyで確認してください。
- ツールを更新するときは、新しい .unitypackage を同じプロジェクトへインポートし、コンパイル後に必要な設定を更新します。
- ギミックを外すときは、対象アバター直下の「かんたん衣装切替」を削除し、衣装の表示状態を手動で整えて保存・再ビルドします。
- 生成先は Assets/FriendWardrobeGenerated です。不要になった生成アセットは、他のアバターや設定から参照されていないことを確認してから削除してください。

## メニューが出ないとき

| 症状 | 確認すること |
| --- | --- |
| UnityのToolsにツールが出ない | SDK・Modular Avatarが導入されているか、Consoleにコンパイルエラーがあるか |
| 作成ボタンが押せない | 衣装が2〜32着か、空欄・重複・親子登録がないか、Play Modeを終了しているか。画面の警告も確認 |
| VRChatに「衣装切替」が出ない | ビルドしたアバターに生成オブジェクトがあるか、MA Menu Installerが有効か、Select Menuの導入先が正しいか |
| 更新前のメニューが出る | 設定変更後に対象アバターを再ビルド・再アップロードしたか |
| 衣装が切り替わらない | 同じ衣装を制御する別のトグルやアニメーションと競合していないか |

元のExpressions Menuアセットの表示だけでは、ビルド時に合成される結果を確認できません。メニュー項目が多い場合は追加ページや指定先のサブメニューも確認してください。 [MA Menu Installer](https://modular-avatar.nadena.dev/docs/reference/menu-installer)
